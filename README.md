# My Daily Journal

Website sederhana untuk menampilkan aktivitas dan kegiatan sehari-hari mahasiswa.

## Fitur

- Halaman artikel dan galeri kegiatan
- Jadwal kuliah
- Profil mahasiswa
- Tampilan dark mode dan light mode
- Menampilkan tanggal dan jam secara real-time
- Tombol kembali ke atas

## Teknologi

- HTML
- Bootstrap 5
- Bootstrap Icons
- CSS
- JavaScript

## Menjalankan Project

1. Clone repository ini.
2. Buka folder project.
3. Jalankan file `index.html melalui browser.
